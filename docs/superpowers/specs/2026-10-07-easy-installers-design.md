# Simple offline installers for Windows and Mac

The user wants versions they can share with ordinary users: download an installer, install the program, then follow the program's game-configuration prompt. No Python setup, scripts, dependency choices or model downloads are part of the end-user flow. Publishing the installers to the existing public GitHub repository is already authorized.

Windows 10/11 x64 receives a Chinese Inno Setup EXE. It installs a PyInstaller onedir application and its verified M2M100 418M CTranslate2 INT8 model into the current user's program directory, creates Start menu/desktop shortcuts and an uninstaller, and can open the program when finished. It does not require administrator rights for the application installation. Dependencies needed for inference are bundled with the application. The installed application must run outside the source tree without the developer's Python or personal settings. Installation and normal translation must work without downloads. Uninstall removes program files and shortcuts while preserving user settings/cache and the Dota game configuration for subsequent installations.

Mac keeps the existing Apple Silicon and Intel DMGs with bundled model/runtime, Applications link and Chinese first-use instructions. All three installers are built for version 0.3.2 and published in one Release. README starts with a simple download table and installation steps, clearly identifying Download ZIP as developer source. Windows-source setup moves into the developer section.

Use the existing per-user settings, startup GSI check, portable Steam discovery, glossary and cache. Keep CPU INT8, default 2 threads/1 worker/shared model and 180-second idle unload. The first game configuration installation remains explicit in the program and requires restarting Dota 2. Do not silently change the user's game files during program setup.

Verify Windows frozen-app relocation into a Unicode/spaced directory, real offline bidirectional inference, GUI, clipboard and loopback GSI, then silently install the actual setup into a temporary directory, run the installed app's self-test, upgrade by running setup again, and uninstall it. Isolate test shortcuts and installer registry state from the user's ordinary installation. Both Mac builds repeat the existing native checks. Publish checksums and reports only after all platforms pass.

This release retains the practical limitations already documented: no Apple Developer ID/notarization or Windows publisher certificate is available, and real Dota matches/FPS require player hardware. Use normal per-app OS first-open options; do not disable system protections. Developer tool downloads come from official sources with recorded verification.
