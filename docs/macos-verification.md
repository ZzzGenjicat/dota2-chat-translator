| 环境 | 回归检查 | 安装包与实际离线自检 |
| --- | --- | --- |
| Windows 2022 / Python 3.12 | 209 项通过 | 保留原有 Windows 启动方式 |
| macOS 14 / Apple Silicon | 201 项通过，8 项 Windows 专属检查跳过 | 原生 arm64 DMG、自检通过 |
| macOS 15 / Intel | 201 项通过，8 项 Windows 专属检查跳过 | 原生 x86_64 DMG、自检通过 |

两种 Mac 架构均使用实际 M2M100 418M CTranslate2 INT8 权重做俄语→中文、中文→俄语推理。打包后的应用被复制到含中文和空格的其他目录，从源码目录之外启动，清除构建机的 Python 路径与个人配置环境变量。验证过程阻止 Python 对外连接，只允许本机回环。

实际应用检查通过：模型和词库定位、粗话词库对应强度、Steam 中文路径查找、GSI 配置安装与本机 HTTP 接收、中文字体、主要按钮完整显示及俄语剪贴板复制。模型加载加两次短句推理合计为 arm64 3.612 秒、x86_64 4.379 秒；这不是单条聊天的延迟或 Dota 对局性能测量。

每种架构发布 DMG、SHA256 校验文件和 `smoke.json`，共 6 个附件。已确认安装包下载地址返回成功，公开报告为 `passed: true`，架构与文件名对应，校验文件与 GitHub 对安装包记录的 SHA256 一致。

Mac GUI 的 25 项用例各在独立进程运行，重启相关用例使用一个 Tk 解释器重建应用状态，避免 Tk Aqua 在同一进程重复创建解释器造成测试停滞。原生验证还发现并修复了遗留翻译定时器导致重复推理，以及 Mac 窗口显示时重置置顶状态的问题。

安装包支持 macOS 14 或更新版本，包含模型及运行环境。默认 2 个 CPU 线程、1 个推理工作器，收发共用模型，空闲 180 秒卸载。源码、模型构建脚本和固定版本校验保留，后续版本可通过相同流程重新生成。

预览版使用本地临时签名，已通过应用签名完整性检查；尚未使用 Apple Developer ID 签名或公证。首次打开方式见安装包内说明。真实 Dota 2 对局的聊天推送、游戏内粘贴与帧率影响仍需 Mac 实机验证。
