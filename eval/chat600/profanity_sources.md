# 粗口聊天语料来源与使用说明

- 文件：`profanity.jsonl`，200 条原创例句；俄→中和中→俄各 100 条，每个方向短句 34 条、中句 33 条、长句 33 条。
- 来源：为本次离线 Dota 2 俄中聊天质量评测独立编写，未抓取玩家聊天、未复制固定短语数据集、未调用在线翻译或待测模型，也未使用外部词典或网页作为句子来源。故无引用 URL。
- 字符长度按 Python `len(source)` 计算，包含空格、标点、拉丁转写与数字。实测俄语短/中/长为 17–34 / 59–78 / 178–225 字符，中文为 7–12 / 22–28 / 72–84 字符。
- 覆盖：游戏表现和物品辱骂、轻度感叹、强烈粗口、性词的惯用骂法、正向粗口、自嘲、反讽、否定、疑问、引用归属、指令范围、字面身体词、俄语拉丁转写、中文拼音/缩写/避写/方言；游戏语境包括团战、对线、补刀、眼、雾、买活、肉山、信使、BKB、幻象和界面/网络问题。
- `severity` 标注的是原句在具体语境中的粗俗强度，0=中性字面/歧义对照，1=轻度抱怨或感叹，2=明显粗口或辱骂，3=强烈粗口。共有 0/1/2/3 级 6/29/105/60 条；强度具有主观性，引用、正向感叹和方言尤其需要人工判断。
- 全部案例自含上下文，未使用 `history` 字段。文件按分批完成顺序追加，行号不等于 ID 的数值；应按 `id` 关联推理结果。
- `reference` 是一种自然译法，不能作为唯一正确措辞。质量应人工审查语义、语气强度、作用范围与流畅度，结合 `must_preserve` 和 `forbidden_meaning`；不得用参考译文子串命中率充当质量分。
- 补充文件 `profanity_reference_corrections.json` 保存 032/069/077/099/114 的五处参考校准建议；当前 JSONL 已冻结以保持运行中 baseline 的摘要一致，未应用这些建议。人工审阅可按 ID 覆盖参考，推理结束后由主任务统一合入。
- 限制：这些是原创合成聊天案例，未证明代表真实玩家分布，也未经俄语母语者双盲复核；中性歧义对照句和长句比真实即时聊天更解释性。未包含对受保护群体的仇恨或新增威胁。
