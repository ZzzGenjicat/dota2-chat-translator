Dota 2 本地聊天翻译 · Windows

1. 双击 windows-x64-setup.exe，点击“安装”。支持 Windows 10/11 64 位。
2. 安装完成后，从桌面或开始菜单打开“Dota 2 本地聊天翻译”。
   Python、翻译模型和运行环境已经包含，安装与翻译无需联网下载。
3. 首次打开会检查游戏配置；缺失时点击“安装游戏直读配置”，然后重启 Dota 2。
   找不到游戏时点击“选择目录”；Steam 自定义库和外置游戏盘也可使用。
4. 点击“开始抓取”，等待游戏推送俄语聊天。
5. 输入中文后自动译成俄语，点击“复制俄语”，在游戏用 Ctrl+V 粘贴。

默认 2 个 CPU 线程、不用 GPU。模型空闲 3 分钟释放，需要时自动加载。
无需安装到 Dota 2 目录，不需要每次重复安装游戏直读配置。
可以在 Windows“设置 → 应用”中卸载；设置和翻译缓存保留，方便重装后继续使用。

此预览版尚无 Windows 发布者证书。系统首次打开提示未知发布者时，
请先核对文件来自本项目的 GitHub 发布页及其校验文件，使用系统为该文件提供的打开选项。
不要关闭系统整体保护。

启动出错时查看 %LOCALAPPDATA%\Dota2ChatTranslator\logs\gui_error.log。
真实 Dota 2 对局推送与帧率影响仍需在自己的电脑上验证。
