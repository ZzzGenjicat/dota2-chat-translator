Windows / Mac 简易安装版：M2M100 418M · CTranslate2 INT8 · CPU。

- Windows 10/11（64 位）下载 `windows-x64-setup.exe`，双击后点“安装”。自动创建桌面和开始菜单快捷方式，支持系统“已安装的应用”卸载。
- Apple 芯片选择 `macos-arm64.dmg`，Intel Mac 选择 `macos-x86_64.dmg`；需要 macOS 14 或更新版本。
- 三个安装包都包含模型和运行环境，无需安装 Python，无需首次启动下载模型。Mac 打开 DMG，将应用拖到 Applications。
- 每次启动自动检查游戏直读配置；缺失时安装一次并重启 Dota 2。支持 Steam 自定义游戏库和手动选择目录。
- 默认 2 个 CPU 线程、收发共用模型；空闲 3 分钟释放。粗话保留词库对应强度，中文→俄语使用 Dota 常见口语和术语。

附件包含 SHA256 校验文件、三个平台的真实 INT8 / GUI / 复制 / GSI / 移动路径离线验证报告，以及 Windows 实际安装、重复安装和卸载报告。

此版本为预览版，尚无 Windows 发布者证书，Mac 使用临时本地签名、尚未经过 Apple 开发者签名和公证。首次打开被系统拦截时，Windows 在这个安装文件的“更多信息”中查看“仍要运行”；Mac 在“系统设置 → 隐私与安全性”查看这个应用的“仍要打开”。安装包内附首次使用说明，无需关闭系统整体保护。

自动构建和离线验证不代替真实 Dota 2 对局测试；游戏聊天推送和帧率影响仍需实机验证。Source code (zip / tar.gz) 是开发者源码，普通用户下载上面的 EXE 或 DMG。
