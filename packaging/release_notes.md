Dota 2 俄语↔中文聊天翻译，支持 Windows 和 Mac，翻译全程在本机完成。

0.4.3 继续使用轻量方案：安装包内置约 494MB 的 M2M100 418M CTranslate2 INT8 模型，装好即可离线翻译，无需 Python 或首次下载模型。不下载或加载 17GB 大模型，已有大模型文件保留。

- 合入整理的英雄、装备、术语、游戏短句和粗话词库，新增 1706 种俄语写法；现有 572 组整句预设、759 个术语或别名组、14 个可控模板。新增内容主要用于俄语→中文。
- `чет изи` / `чёт изи` 直接译为“怎么这么轻松”，无需加载模型。模型输出异常时保留原文，修复短句被错误提示“请拆成短句”的问题。
- 游戏直读支持 42 个明确列出的拉丁字母俄语写法，例如 `cyka`、`idi nahui`。只匹配整句白名单，避免误收普通英文。
- 保留粗话强度、否定和对象；共享英雄缩写、普通词昵称等歧义写法不做无条件替换。词库改变后自动隔离旧缓存。

默认 2 个 CPU 线程、不使用 GPU，空闲三分钟释放模型。不使用屏幕识别。自由聊天和复杂长句仍可能误译；选人和赛后聊天漏收尚未解决。

| 电脑 | 下载文件 | 安装 |
| --- | --- | --- |
| Windows 10/11，64 位 | `windows-x64-setup.exe` | 双击后点“安装” |
| Apple 芯片 Mac | `macos-arm64.dmg` | 拖到“应用程序” |
| Intel Mac | `macos-x86_64.dmg` | 拖到“应用程序” |

Mac 需要 macOS 14 或更新版本。首次按程序提示安装一次游戏直读配置，重启 Dota 2 后点击“开始抓取”。输入中文后点击“复制俄语”，粘贴到游戏发送。不使用屏幕识别；选人和赛后聊天漏收尚未解决。

本版本暂未取得系统认可的发布签名。首次被拦截时，Windows 查看“更多信息 → 仍要运行”；Mac 尝试打开一次后，查看“系统设置 → 隐私与安全性 → 仍要打开”。无需关闭系统整体保护。

使用与源码本地模型安装方法见[轻量版源码首页](https://github.com/ZzzGenjicat/dota2-chat-translator/tree/codex/lightweight-offline)。普通用户下载 EXE 或 DMG；Source code 是源码，校验文件无需下载。
