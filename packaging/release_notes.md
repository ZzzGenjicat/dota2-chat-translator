Dota 2 俄语↔中文聊天翻译，支持 Windows 和 Mac，翻译全程在本机完成。

本预览版使用 Hy-MT2 30B-A3B Q4，整句翻译，参考最近三条、45 秒内的聊天原文。默认 2 个 CPU 线程、不用 GPU，空闲三分钟释放模型。

0.4.1 修正中文长句输出空间不足、部分粗话词序导致译文无法结束的问题，补充买活、复活、视野、英雄技能及俄语词形。旧译文缓存自动隔离；模型和原有设置保留。粗话强度、否定和引用对象仍可能翻错，复杂句子需要核对。

需要至少 32 GB 总内存和 22 GB 当前可用内存，运行约占 17 GB。这是较大模型的试用版，省略对象、错字、复杂黑话仍可能误译，无法保证秒出结果。

不使用屏幕识别。选人和赛后聊天可能漏收，目前尚未解决；截图中含义不明的“потипай”保留原文并提示，陌生黑话仍可能误译。

| 电脑 | 下载文件 | 安装 |
| --- | --- | --- |
| Windows 10/11，64 位 | `windows-x64-setup.exe` | 双击后点“安装” |
| Apple 芯片 Mac | `macos-arm64.dmg` | 拖到“应用程序” |
| Intel Mac | `macos-x86_64.dmg` | 拖到“应用程序” |

安装包包含运行环境，无需安装 Python。首次打开自动下载约 17 GB 模型并校验，之后翻译全程离线；界面会显示准备进度。Mac 需要 macOS 14 或更新版本。

首次按程序提示安装一次游戏直读配置，重启 Dota 2 后点击“开始抓取”。输入中文后，点击“复制俄语”，粘贴到游戏发送。

本预览版暂未取得系统认可的发布签名。首次被拦截时，Windows 查看该文件“更多信息 → 仍要运行”；Mac 尝试打开一次后，查看“系统设置 → 隐私与安全性 → 仍要打开”。无需关闭系统整体保护。

本地模型安装和使用方法见[预览源码首页](https://github.com/ZzzGenjicat/dota2-chat-translator/tree/codex/context-local-model)。普通用户只需下载 EXE 或 DMG，校验文件可忽略；Source code 是源码。

[600 条前后译文与评测](https://github.com/ZzzGenjicat/dota2-chat-translator/blob/codex/context-local-model/eval/chat600/results/report.md)：模拟样本辅助评分的可用结果从 242/600 提高至 335/600，单独验证从 51/120 提高至 60/120。中文长句转俄语仍不稳定，尚不适合作为可靠译文直接发送。
