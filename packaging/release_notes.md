Dota 2 俄语↔中文聊天翻译，支持 Windows 和 Mac，翻译全程在本机完成。

本次修正截图中的外挂、英雄名和粗话误译，增加俄语词形、否定句及常见游戏口语；升级后自动使用新翻译缓存。继续使用 M2M100 418M INT8 和默认 2 个 CPU 线程。

不使用屏幕识别。选人和赛后聊天可能漏收，目前尚未解决；截图中含义不明的“потипай”保留原文并提示，陌生黑话仍可能误译。

| 电脑 | 下载文件 | 安装 |
| --- | --- | --- |
| Windows 10/11，64 位 | `windows-x64-setup.exe` | 双击后点“安装” |
| Apple 芯片 Mac | `macos-arm64.dmg` | 拖到“应用程序” |
| Intel Mac | `macos-x86_64.dmg` | 拖到“应用程序” |

安装包已内置本地模型和运行环境，无需安装 Python 或另下模型。Mac 需要 macOS 14 或更新版本。

首次按程序提示安装一次游戏直读配置，重启 Dota 2 后点击“开始抓取”。输入中文后，点击“复制俄语”，粘贴到游戏发送。

本预览版暂未取得系统认可的发布签名。首次被拦截时，Windows 查看该文件“更多信息 → 仍要运行”；Mac 尝试打开一次后，查看“系统设置 → 隐私与安全性 → 仍要打开”。无需关闭系统整体保护。

本地模型安装和使用方法见[项目首页](https://github.com/ZzzGenjicat/dota2-chat-translator)。普通用户只需下载 EXE 或 DMG，校验文件可忽略；Source code 是源码。
