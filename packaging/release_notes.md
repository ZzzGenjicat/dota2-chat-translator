0.4.4 将已审校的俄译中词库和指令修复打入 Windows、Apple 芯片 Mac 与 Intel Mac 安装包。装好即可离线使用，内置约 494MB 的 M2M100 418M INT8 模型，无需另装 Python 或首次下载模型。

- 词库现有 1247 组整句、896 组术语或别名、22 个模板及 64 条拉丁输入白名单，包含第二、第三套文档筛选后的俄译中内容。
- 改善购买／别购买、肉山／魔方目标切换、技能状态及部分连续指令，例如 `go tormentor ne rosh` →“打魔方，别打肉山”。
- 修正部分俄语词形、英雄外号、主客体和粗口强度；不明确的英雄外号只在明确语境中匹配。词库变化后自动隔离旧缓存。
- 默认仍是经过现有流程验证的原始小模型。新语料已完成真实微调，但实验候选仍有新增粗口、指代及否定错误，因此没有打入安装包。原始训练文档和逐句审计保留在本机，不随软件公开。

自由长句、错拼、否定和复杂黑话仍可能误译；有限的生成检查不能拦住所有错误。选人和赛后聊天漏收尚未解决。主要优化俄语→中文，中文→俄语功能保留。

| 电脑 | 下载文件 | 安装方法 |
| --- | --- | --- |
| Windows 10/11，64 位 | `windows-x64-setup.exe` | 双击安装 |
| Apple 芯片 Mac，macOS 14+ | `macos-arm64.dmg` | 拖到“应用程序” |
| Intel Mac，macOS 14+ | `macos-x86_64.dmg` | 拖到“应用程序” |

首次按程序提示安装游戏直读配置，重启 Dota 2 后点击“开始抓取”。中文输入翻译后点击“复制俄语”，粘贴到游戏发送。

默认 2 个 CPU 线程，日常翻译不使用 GPU，空闲三分钟释放模型。不使用屏幕识别。三平台安装包均由各自的原生环境构建，发布前执行回归、离线推理、移动路径、界面／剪贴板检查；Windows 另验证安装、重装和卸载。

暂未取得系统认可的发布签名。Windows 首次可能需点“更多信息 → 仍要运行”；Mac 首次可能需在“系统设置 → 隐私与安全性”允许打开。无需关闭系统整体保护。
